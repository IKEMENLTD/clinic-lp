## 参照LPのデザイン特徴（再実装時のトークン）

- 配色: 水色×白基調（泡・キラキラの装飾）、価格・強調はピンク、FAQ帯はティール
- 見出し: 明朝系ディスプレイ＋装飾記号（＼／・＋〜＋）
- 価格表現: 月額を大きく・総額を小さく併記。割引合計額を明示
- CTA: ページ内に購入CTAを3回以上反復。処方不可時の注記をCTA直下に配置
- 信頼要素の順番: 価格→希少性→プラン→保証→機序→社会的証明→FAQ（**価格先出し型**。Clinic For型の悩み共感先出しと対照的）
