# Re:Design Clinic LP

オンライン診療（医療ダイエット・ピル・美容内服・エクソソーム・ED・AGA）のランディングページ。

## 構成（4バージョン併存）

- `index_pixel.html` — **1px準拠スケルトン**。参照LP2の実測ジオメトリ（画像領域13枠の寸法・ウィジェット/CTA/FAQの組版）に1px単位で一致。画像はフレームのみ（F-01〜F-12, G-01〜07）。実測値はファイル冒頭コメントと `docs/reference-auravita.md` 参照
- `index_trial.html` — 価格先出しEC型ファネル（自前デザイン版）

- `index.html` — **再構築版（本命）**。医療ダイエット主訴求の長尺LP。画像は全て「同寸法フレーム＋生成プロンプト」のプレースホルダ（P-01〜P-30）。ビルド不要の静的サイト
- `index_original.html` — **原本の忠実コピー**。クローン元サイトそのまま。`assets/img/` の画像を参照する
- `assets/img/` — 原本の画像一式（index_original.html 用。再構築版の画像差し戻し時の参考にも使う）
- `docs/reference-structure.md` — 参照LPの構成分析と対応表（取得物はローカル `C:\Users\ooxmi\clinic-lp-reference\` に保管、リポジトリ外）

## 再構築版の画像プレースホルダ

各フレーム内のプロンプトを画像生成AIに渡して実画像を作り、`<div class="ph-frame">…</div>` を `<img>` に差し戻す運用。商品画像のプロンプトは `index.html` 内 `IMG_PH` オブジェクトに集約。P-27〜P-30は増設セクション用の新規画像。

セクション順: 訴求バー → ヒーロー（オファーカード＋CTA）→ 医師バナー → 定期バナー → プラン分岐（定期/単品/目的別メニュー）→ 価格マトリクス＋他カテゴリアコーディオン → 受付フォトバンド＋利便性 → 医師のお約束 → 実感値 → オンライン予約説明 → ATTENTION → オファー反復 → 悩み提起 → GLP-1メカニズム → 製品詳細（グラフ＋Point）→ いつもの生活バンド → 相談クロージング＋お約束反復 → 感情バンド → ライフチェンジ → 利用の流れ → FAQ → CTA → 未承認医薬品の重要事項 → フッター

## 画面遷移（両バージョン共通）

ハッシュルーティングで擬似ページ遷移する。

- `#cat-p_xxx` — カテゴリ一覧（例: `#cat-p_himan`）
- `#product-xxx` — 商品詳細（例: `#product-manjaro-25`）
- `#teiki` — 定期購入ページ

商品データ（価格・効果・副作用・定期購入プラン）は各HTML内の `groups` オブジェクトに集約。価格改定・商品追加はここを編集する。

## デプロイ

静的ホスティング（Netlify / GitHub Pages 等）にそのまま配置可能。
